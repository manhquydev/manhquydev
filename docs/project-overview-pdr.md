# Project Overview & Product Development Requirements (PDR)

## Project Purpose
Maintain a concise, professional, auto-updated GitHub profile README for `manhquydev`. The README presents an authentic, research-backed overview of background, selected work, stack, and activity heatmap with minimal manual upkeep.

## Target Audience
- Technical recruiters and hiring managers
- Potential collaborators

## Functional Requirements
- **Single language**: All content in English; no bilingual sections.
- **Auto-updated marker block**: Single marker pair in `README.md` regenerated by `scripts/update-readme.js`:
  - `CONTRIBUTION-GRAPH`
- **Data pipeline**: `scripts/fetch-github-metrics.js` writes `data/github-metrics.json`. Runs via the daily `update-project-stats.yml` Actions workflow, followed by `scripts/update-readme.js`.
- **Contribution heatmap**: `assets/readme/contribution-heatmap-light.svg` and `-dark.svg` generated from the contribution calendar in the metrics data.
- **Header banner**: `assets/readme/banner-light.svg` and `-dark.svg` (typographic banner with name, positioning, location/remote availability, single-hue muted slate palette, light/dark switching via `<picture>`).
- **Selected Work**: `assets/readme/work-light.svg` and `-dark.svg` (4 compact project cards: FlowSkill, Sentinel, VietExplore AI, Ephemera with status indicators and tech tags), accompanied by a compact plain-markdown index.
- **Tech stack**: Categorized 2-column table; no badge-service images.
- **Contact links**: Plain-text links in a "Connect" section.
## Non-Functional Requirements
- No third-party decorative widgets (no typing SVG, capsule-render, quotes, or badge-style services).
- Minimal external requests at render time; all data baked into the README and local SVGs.
- Readable in both GitHub light and dark themes.
- Automation entirely via `update-project-stats.yml` (daily at 03:00 UTC plus manual dispatch).

## Acceptance Criteria
- The single marker pair (`CONTRIBUTION-GRAPH:START` / `END`) is present in `README.md`.
- `node scripts/update-readme.js` is idempotent when `data/github-metrics.json` is present and populated.
- `node scripts/update-readme.js` exits with code 1 and does not modify `README.md` or the heatmap SVGs when `data/github-metrics.json` is missing or empty.
- The contribution heatmap SVGs regenerate from `data/github-metrics.json`.
- Header banner and Selected Work SVGs are self-contained local files in `assets/readme/`, render valid XML, adhere to the single-hue muted palette, and switch themes cleanly via `<picture>`.
- Research rationale and design principles documented in `plans/2026-10-12-profile-patterns-research.md`.
